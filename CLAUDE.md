### Asset handling

Until the asset library is manually remapped:
- treat `assets/` as quarantined
- use placeholders when an approved Canva export is not yet available
- label placeholders clearly by intended Canva source/role
- do not use Replit-era images, fake watercolor assets, generated tickets, generic AI imagery, or arbitrary files from the legacy folders
- do not infer brand direction from legacy filenames

The correct workflow is:

**inspect Canva → establish design system → build layout → map/export approved assets later**

Do not reverse that workflow by starting from whatever files happen to exist in the repository.

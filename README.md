# Lorraen Madre Website

## Asset source of truth

**Canva is the authoritative visual source for this project.**

Do **not** use files in this repository's legacy `assets/` folders as the design reference for new builds unless Rae explicitly approves a specific file.

The current `assets/` directory contains older exports, experiments, Replit-era material, and unsorted files. It is being kept temporarily for later cleanup only. Treat it as **quarantined / non-authoritative**.

The **Aqui Theme — Home Video Version** is a layout and interaction reference only. It is not an asset source.

Use it for ideas such as:

Do not copy its brand assets.

## Important build rule

Before creating or redesigning the site:

1. Inspect the Canva references first.
2. Derive the visual system from those references.
3. Use the current product / narrative brief for information architecture and copy.
4. Do not automatically import or select images from `assets/`.
5. Do not invent substitute logos, watercolor art, tickets, icons, or generic AI imagery when a Canva reference exists.

### Explicitly rejected directions

Do not recreate or revive:
- Replit-generated / Replit-inspired assets
- generic AI startup visuals
- faux vintage ticket / county-fair aesthetics
- generic SaaS cards
- neon or AI-purple gradients
- glassmorphism
- cartoon fairy graphics
- random mystical clip art
- stock corporate people

## Current design principle

**AQUI = structural reference**  
**CANVA = brand source of truth**  
**PRD / narrative brief = content + information architecture**

The job is to translate the existing Lorraen Madre brand into the new website narrative, not redesign the brand from scratch.
